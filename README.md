# 智能药盒手机网页

本项目是与《智能药盒 产品说明与 PRD》对应的手机尺寸网页。包含创建计划、整理文字或照片中的已有安排、核对字段、绑定 1 至 3 号药格、今日任务、开盒与服用确认分离、待核实、记录时间线和到期归档。处方照片字段完整时可生成定时计划草稿；选择说明书照片后会自动识别并填入分人群单次用量和使用限制，打开计划草稿；用户核对适用人群、用途与日期后建立按需或定时计划。按需计划不会把“每隔若干小时可重复使用”变成固定提醒。右下角“用药助手”可查询当前计划、预置的有来源药品资料，也可对照用户上传并核对过的说明书文字回答。

环境和运行步骤见 [requirements.md](requirements.md)。主要文件：`server.py` 为本地网页及百炼接口服务，`web/` 为页面，`test_api_key.py` 为独立密钥检测脚本，`tests/` 为自动化测试。

运行测试：

```powershell
node --test tests/*.test.js
python -m unittest discover -s tests -p "test_*.py"
```

测试场景与操作步骤见 [TEST_CASES.md](TEST_CASES.md)。
